1. git clone <url> – копирует удалённый репозиторий к себе на компьютер.

2. git status – показывает, что сейчас происходит в репозитории: какие файлы изменены, какие добавлены в индекс, а какие ещё не отслеживаются.

3. git add <файл> – добавляет файл в индекс, то есть подготавливает его к сохранению в следующем коммите.

4. git commit -m "сообщение" – сохраняет все добавленные изменения, создавая новую точку в истории проекта.

5. git push – отправляет все локальные коммиты в удалённый репозиторий (например, на GitHub).

6. git pull – забирает свежие изменения с удалённого репозитория и сливает их с моей текущей веткой.

7. git branch – показывает список веток в репозитории, текущая ветка выделена звёздочкой.

8. git checkout <ветка> – переключает меня на другую ветку.

9. git merge <ветка> – вливает изменения из указанной ветки в текущую.

10. git log – показывает историю коммитов с их хешами, авторами и датами.

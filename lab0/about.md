# Что такое Git и для чего он используется?

Git это программа, которая сохраняет историю изменений в файлах. Она нужна, чтобы не бояться что-то сломать, потому что всегда можно вернуться к старой версии. Ещё Git позволяет нескольким людям работать над одним проектом одновременно и не мешать друг другу. А ещё он показывает, кто, когда и что менял.

# В чём разница между централизованными и распределёнными системами контроля версий?

В централизованных системах всё хранится на одном главном компьютере. Чтобы посмотреть историю или сохранить изменения, нужен интернет. Если этот компьютер сломается, работать никто не сможет.
В распределённых системах у каждого есть полная копия проекта на своём компьютере. Можно работать без интернета, сохранять изменения и смотреть историю. Если главный компьютер сломается, проект можно восстановить с любого другого компьютера, где он есть.

# Что такое репозиторий в Git?
Репозиторий это просто папка с проектом, в которой Git хранит все изменения. Внутри есть скрытая папка .git, там лежат записи о том, кто, когда и что менял. Всё остальное это просто файлы и папки самого проекта.
